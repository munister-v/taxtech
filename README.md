# TaxTech

Віртуальна лабораторія цифрових фінансів і технологій розподіленого реєстру.

Наукова робота «Метод інтелектуального вибору між локальними та хмарними обчисленнями в мобільних застосунках»
на прикладі фінансового асистента з навчальним банком на віртуальних грошах.

Застосунок для кожної ІІ-задачі вирішує, де її виконати: на iPhone, на сервері чи на сервері після маскування
особистих даних - і пише кожне рішення в журнал для аналізу.

## Частини

- `EdgeRouter/` - Swift-пакет із методом. Тести: `swift test`.
  - `EdgeRouter` - контекст телефона, оцінки часу й якості, модель енергії, політика drift-plus-penalty
    з чергою Ляпунова, каскад з адаптивним конформним порогом, маскування, журнал.
  - `FraudLite` - Layer 1 антифроду з сервера, перенесений один до одного; збіг із Python перевіряють
    454 еталонні вектори.
- `ios/` - SwiftUI-застосунок (iOS 26). Вкладка Studio: сім дослідів із теорією, живим дослідом і перевіркою з
  трьох питань (маршрутизація телефон чи сервер, антифрод на телефоні, подвійний запис, ідемпотентність,
  холд коштів, хеш-ланцюг, печатка документа); працює без мережі й без входу. Після входу відкривається
  навчальний банк: Piazza, Registro, Carte, Fisco, помічник, чек. Магазин є лише в DEBUG-збірці.
  Проєкт генерується: `cd ios && xcodegen generate`.
  Для перевірки в симуляторі DEBUG-збірка читає змінні `KOPIYKA_TAB`, `KOPIYKA_SIGNED_OUT=1`,
  `KOPIYKA_EXPERIMENT=<router|fraud|ledger|idempotency|hold|chain|seal>`, `KOPIYKA_PART=lab|quiz`.
- `server/` - урізаний бекенд `munister-v/army-bank`: навчальний банк, повний антифрод (усі шари, SQLite
  або Postgres), `/api/research/*`, розмічені синтетичні дані. Запуск і ендпоінти - [server/README.md](server/README.md).

Повний опис дослідження (постановка задачі, формули, карти рішень, набір даних, паритет, література,
стандарти) - [docs/RESEARCH.md](docs/RESEARCH.md). Сайт <https://bank.munister.com.ua> показує сам банк.

## Задачі, які маршрутизуються

| Задача | На телефоні | На сервері | Дані |
|---|---|---|---|
| Перевірка переказу | `FraudLite`, Layer 1 | усі шари з історією й графом | відкриті для свого банку |
| Чек | правила розбору тексту Vision | мовна модель, текст після маскування | особисті |
| Помічник | Foundation Models | мовна модель, після маскування | особисті |

Фото чека завжди розпізнається на телефоні; на сервер іде лише текст.

## Стратегії для порівняння

«Завжди телефон», «Завжди сервер», «Прості правила», «Каскад» і метод EdgeRouter - перемикаються в «Лабораторії».
Там же параметри α, V, бюджет енергії і експорт журналу (`decisions.jsonl`).

## Що ще не зроблено

- Коефіцієнти моделі енергії - стартові з літератури; їх треба відкалібрувати Power Profiler на своїх iPhone.
- Невпевненість антифроду на телефоні - евристика; її треба навчити на `research_labels`.
- Foundation Models не підтримує українську (перевірено в симуляторі): потрібна своя локальна модель.
- Мовна модель на сервері потребує `ANTHROPIC_API_KEY` у `server/.env`.
